## Getting Started

### First Time Login

1. Navigate to the admin login page: `https://yourdomain.com/admin/login`
2. Use the default credentials:
   - Email: `galimanasa3@gmail.com`
   - Password: `Admin@123`
3. **IMPORTANT:** Change your password immediately after first login

### Changing Your Password

1. Go to **Settings** from the sidebar
2. Click on **Change Password**
3. Enter your current password
4. Enter your new password (minimum 8 characters, including uppercase, lowercase, and numbers)
5. Confirm your new password
6. Click **Update Password**

## Login & Authentication

### Login Process

1. Enter your email address
2. Enter your password
3. (Optional) Check "Remember Me" to stay logged in
4. Click **Login**

### Session Management

- Sessions expire after 24 hours of inactivity
- You'll be automatically logged out when the session expires
- Use the **Logout** button in the top right to manually log out

### Security Tips

- Never share your admin credentials
- Use a strong, unique password
- Log out when using shared computers
- Enable two-factor authentication if available

## Managing Profile

### Profile Information

1. Navigate to **Profile** in the sidebar
2. Update the following fields:
   - **Full Name** - Your complete name
   - **Professional Title** - Your job title/role
   - **Professional Summary** - Brief bio (supports rich text)
   - **Email** - Contact email
   - **Phone** - Contact phone number
   - **Location** - City, State/Country
   - **Years of Experience** - Total years in the field

### Profile Photo

1. Click **Upload Photo** or drag and drop an image
2. Supported formats: JPEG, PNG, WebP
3. Maximum size: 5MB
4. Recommended dimensions: 400x400px (square)
5. Preview the image before saving
6. Click **Save Changes**

### Resume Upload

1. Click **Upload Resume**
2. Supported formats: PDF, DOCX
3. Maximum size: 10MB
4. The current resume will be replaced
5. Click **Save Changes**

### Social Media Links

Add links to your professional profiles:

- LinkedIn
- GitHub
- Twitter
- Medium
- Stack Overflow

**Format:** Enter the complete URL (e.g., `https://linkedin.com/in/yourprofile`)

## Managing Skills

### Adding a New Skill

1. Navigate to **Skills** in the sidebar
2. Click **Add New Skill**
3. Fill in the form:
   - **Skill Name** - Technology or skill name
   - **Category** - Group (e.g., Data Analysis, Data Engineering)
   - **Proficiency** - Level from 1-100
   - **Icon** - Optional icon name or URL
4. Click **Save**

### Editing Skills

1. Find the skill in the list
2. Click the **Edit** button
3. Update the information
4. Click **Save Changes**

### Deleting Skills

1. Find the skill in the list
2. Click the **Delete** button
3. Confirm the deletion

### Reordering Skills

1. Use drag-and-drop to reorder skills
2. The order will be reflected on the public portfolio
3. Changes are saved automatically

### Skill Categories

Organize skills into logical categories:

- Data Analysis
- Data Engineering
- Business Intelligence
- Databases
- Tools & Technologies
- Programming Languages

## Managing Projects

### Adding a New Project

1. Navigate to **Projects** in the sidebar
2. Click **Add New Project**
3. Fill in the form:
   - **Title** - Project name
   - **Short Description** - Brief summary (1-2 sentences)
   - **Full Description** - Detailed description (supports rich text)
   - **Technologies** - Tags for technologies used
   - **Category** - Project type
   - **Status** - Draft or Published
   - **Featured** - Mark as featured project

### Project Images

1. Click **Upload Images** or drag and drop
2. Supported formats: JPEG, PNG, WebP
3. Maximum size: 5MB per image
4. Upload multiple images for a gallery
5. Add captions to images
6. Reorder images by dragging

### External Links

Add links to:

- **Live Demo** - Working project URL
- **GitHub Repository** - Source code
- **Case Study** - Detailed documentation

### Publishing Projects

- **Draft** - Not visible on public portfolio
- **Published** - Visible to all visitors
- Toggle status anytime

### Featured Projects

- Mark important projects as "Featured"
- Featured projects appear prominently on the homepage
- Limit to 3-5 featured projects for best impact

### Backup & Restore

#### Creating a Backup

1. Go to **Settings** > **Backup**
2. Click **Create Backup**
3. Download the backup file
4. Store securely (includes all content and media)

#### Restoring from Backup

1. Go to **Settings** > **Restore**
2. Click **Choose File**
3. Select your backup file
4. Click **Restore**
5. Confirm the restoration
6. Wait for completion (may take 30-60 seconds)

⚠️ **Warning:** Restoring will replace all current data!

## Troubleshooting

### Common Issues

#### Cannot Login

**Problem:** Invalid credentials error

**Solutions:**

1. Verify email address is correct
2. Check password (case-sensitive)
3. Clear browser cache and cookies
4. Try password reset (if available)
5. Contact system administrator

#### Images Not Uploading

**Problem:** Upload fails or times out

**Solutions:**

1. Check file size (must be under limit)
2. Verify file format is supported
3. Try a different browser
4. Compress the image
5. Check internet connection

#### Changes Not Appearing

**Problem:** Updates don't show on public site

**Solutions:**

1. Click "Save Changes" button
2. Refresh the public portfolio page
3. Clear browser cache
4. Wait 1-2 minutes for updates
5. Check if item is published (not draft)

#### Session Expired

**Problem:** Logged out unexpectedly

**Solutions:**

1. Log back in
2. Check "Remember Me" for longer sessions
3. Avoid long periods of inactivity
4. Save work frequently

### Error Messages

#### "Validation Error"

- Check all required fields are filled
- Verify email format is correct
- Ensure dates are in correct format

#### "File Too Large"

- Reduce image/file size
- Use compression tools
- Check maximum size limits

#### "Network Error"

- Check internet connection
- Try again in a few moments
- Contact support if persists
